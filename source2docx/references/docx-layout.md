# DOCX 版面与精确行数控制

## 排版方式

**连续段落** + EXACTLY 行距（twips 整数），**不**插入手动分页符，**不**用表格。

- 移除 `Document()` 默认空段落
- 去掉文档网格（docGrid），避免与行距冲突
- 一行源码 = 一个段落

## 空行（重要）

**禁止用单个空格 `" "` 占位空行。** 在 Word（尤其宋体）下，仅含空格的段落/行会触发异常分页，表现为整页空白；手动删该空格后内容才接上。

空行写法：

```xml
<w:t xml:space="preserve"></w:t>
```

即 `add_run("")` 并对 `w:t` 设 `xml:space="preserve"`。

含缩进的空行（如 `"    "`）保留原空格，不当作空行。

## 控制符

源码行内 `\f`（换页符）、`\v` 等须剔除，否则 Word 会强制换页。

## 字体

宋体、五号（10.5pt），段前段后 0。

## 行距

```text
line_spacing_twips = (页高 − 上下边距 twips) // lines_per_page
```

## 生成策略

先 master 全量连续段落，再按页范围拆份子 docx（逻辑页统计不变，写入仍为连续流）。
