# 周报生成流程

1. 确定模块

根据用户指定的模块，一般为本地项目目录名，例如：rhea，即表示当前项目的上级目录下的rhea这个目录，可以同时指定多个项目

寻找其他模块时，需要进入父级目录

确定目录名时，根据输入的模块名，寻找与之较为匹配的目录名，例如：用户说rhea，则表示这是个关键词，可以匹配 rhea-fe或rhea或rhea-fe-all

如果未具体指定，则表示当前模块

2. 获取git提交用户名

通过 `git config --global user.name` 获取

3. 确定时间范围

根据用户描述确定时间范围，例如用户说本周，则表示从本周一到周日

如果未具体指定，则表示本周

4. 获取提交记录

按下面的命令逐个项目查询提交记录及代码量的简单统计：

```
git log -C "../other-project" --all --author="<用户名>" --since="<开始时间>" --until="<结束时间>" --oneline --date=short --pretty=format:"%ad : %s"
```

`-C` 参数用于指定要查看的模块目录，如果是当前模块，则可省略；可以使用相对路径

5. 填写统计表

根据获取到的所有的提交记录，按模块、项目分支、日期填入如下面的表格，如果没有提交记录，则留空即可

模块名：即为每一步指定的模块

项目：根据提交记录的scope部分来确定提交所属的客户分支，例如："2026-01-13 : fix(zhonghangxin): 问题修复"，表示该提交是 zhonghangxin 这个客户分支的；如果scope为"2.2.9.0"、"2.2.9"、"2.2.9.0+"这种，则统计为"标品"

| 模块   | 项目     | 一（1-19）  | 二（1-19） | 三（1-19） | 四（1-19） | 五（1-19） | 六（1-19） | 七（1-19） |
| 模块一  | 项目一  |             |           |            |           |            |           |           |

6. 生成报告

将上一步填写完成的统计表生成为一个本地的md文档输出到当前目录的根目录下
