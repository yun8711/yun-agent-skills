# kd-fe 项目开发指南

本指南提供完整的开发规范、模板和最佳实践，帮助团队快速开发 Vue2 项目。

## 使用场景

在以下情况下应用此技能：

- 检查项目目录结构是否完整且符合团队规范
- 检查项目中各依赖项、配置项是否完整且符合团队规范
