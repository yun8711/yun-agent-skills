# 示例

## 空仓完整配置

用户：帮这个 Vite + Vue3 项目配 eslint 和 prettier。

1. 画像：Vue3、Vite、pnpm、无质量配置 → 用户确认。
2. 检查：未配置 → 用户选进入完整配置。
3. 能力面、工具、风格均为选项 + 说明（工具不预选）。
4. 汇总确认后安装、写根目录配置、烟雾验证。

## 已有仓只修冲突

画像含 Prettier + ESLint 且 ESLint 仍开 `indent`。用户选「只修」，勾上重叠规则这一条。跳过风格访谈。汇总仅含关闭重叠规则（及 eslint-config-prettier 类依赖）。覆盖策略问一次后写入。
