# 笔记模板

记录笔记时，根据内容类型选用对应格式。**独立条目**之间用单独一行 `---`，上下各一空行；**同一条目内**仅用 `##` / `###` 分级，勿用小节间 `---`。

---

## 一、问题

**适用**：故障排查、报错、异常现象

```markdown
[TOC]

### [问题标题]

表现：

[现象描述，可贴报错信息]

原因：

[原因分析]

解决方案：

[解决步骤或配置，可含代码块]
```

---

## 二、知识点

**适用**：概念、原理、API、技巧；**以外链文章、文档为主的参考与收藏**也一律用本类型——若材料来自网页或指定 URL，须在条目中写明**可点击的原文链接**（便于复核，不必再单独使用「链接」类）。

```markdown
[TOC]

## [主题标题]

**原文**：（可选）若来源为网页/外部文档，填写 `[页面标题](URL)`

### [小节标题]

[要点内容；若以收藏为主，可在此写短摘要或关键句，复杂内容继续用小节展开]

[示例代码或说明]
```

---

## 三、备忘

**适用**：临时记录、待办、自由格式

```markdown
### [标题]

[自由内容]
```
