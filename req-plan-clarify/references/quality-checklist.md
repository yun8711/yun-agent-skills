# 回写前自检清单

交付前逐项核对；任一项失败则补全后再交给用户。

## 文档与 Git

- [ ] 目标文件在 `req_docs/`（或用户指定路径）
- [ ] 项目 `.gitignore` 已包含 `req_docs`
- [ ] 回写内容无「讨论过程 / 问答记录」章节

## 结论完整性

- [ ] 用户确认过的每一条技术细节均已写入对应需求条文或计划表
- [ ] 计划表含落点文件与建议开发顺序
- [ ] 明确「本期 mock / 不改代码」等边界（若适用）

## 与现状一致

- [ ] 落点路径与 Step 2 映射一致，无凭空文件名

## 门禁

- [ ] 未在未授权情况下修改业务代码
- [ ] 交付时询问是否开始实现；未授权则停止
